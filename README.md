# 🌸 FLOREA — Florería Virtual

**FLOREA** es un proyecto web dedicado a la presentación y venta de rosas y flores, diseñado para ofrecer una experiencia visual elegante, delicada y agradable para los amantes de las flores.

## 🌷 Descripción del proyecto

FLOREA es una página web de una florería virtual que busca destacar la belleza de las flores mediante un diseño moderno, una paleta de colores rosados y una presentación atractiva de sus productos.

El proyecto está organizado para desarrollar sus diferentes secciones utilizando ramas de Git, facilitando el trabajo independiente y el control de versiones.

## 🎯 Objetivos

- Diseñar una página web atractiva para una florería.
- Presentar diferentes variedades de rosas y flores.
- Crear una interfaz visual armoniosa y fácil de navegar.
- Practicar el uso de Git y GitHub para gestionar versiones.
- Organizar el desarrollo mediante ramas independientes.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS3:** estilos, colores, distribución y diseño adaptable.
- **Git:** control de versiones.
- **GitHub:** alojamiento del repositorio y gestión del código fuente.

## 🌹 Secciones del proyecto

- **Header:** encabezado, logotipo y menú de navegación.
- **Body:** contenido principal, presentación de flores y catálogo de productos.
- **Footer:** pie de página, información de contacto y enlaces de interés.

## 🌿 Estructura de ramas

| Rama | Función |
|---|---|
| `main` | Rama principal del proyecto. |
| `feature-head` | Desarrollo del encabezado. |
| `feature-body` | Desarrollo del contenido principal. |
| `feature-footer` | Desarrollo del pie de página. |

## 💻 Instalación y ejecución

1. Clona el repositorio:

   ```bash
   git clone https://github.com/diazdavilajesus16-stack/FLOREA.git
   ```

2. Ingresa a la carpeta:

   ```bash
   cd FLOREA
   ```

3. Abre el archivo `index.html` en tu navegador o abre el proyecto en Visual Studio Code:

   ```bash
   code .
   ```

## 🌼 Control de versiones

Para registrar cambios en Git:

```bash
git add .
git commit -m "Descripción de los cambios"
git push
```
